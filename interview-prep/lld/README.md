# Low-Level Design (LLD)

Each design gets its own folder: `lld/<design-name>/` containing `README.md` (use TEMPLATE.md), C++ code, and GTest tests.

## Designs checklist
- [ ] Thread-safe bounded queue
- [ ] Rate limiter
- [ ] Pub/sub sensor message bus
- [ ] Driver/hardware validation framework (generic, self-written example only)
- [ ] LRU cache
- [ ] Thread pool
